# Concept references

Reference sheets for the bodies in Half D, generated with Codex's built-in image
generation and kept here because they are not reproducible: asking again gives a
different creature, and these are what the models were built against.

Downscaled to 900 px. The originals were two megabytes each and `screenshots/`
is gitignored, so keeping them there meant losing them.

| File | For |
| :--- | :--- |
| `quadruped_mutant.png` | An infected on four limbs. Low and wide where everything else in the horde is tall and narrow. |
| `bulwark_mutant.png` | Wider than it is tall. Something to go around rather than through. |
| `lantern_mutant.png` | Glowing from inside. The only thing that emits light in a dark arena. |
| `survivor_lineup.png` | Three survivors with distinct silhouettes, for the multiple-character work. |

The direction is post-apocalyptic with supernatural elements: survivors stay
human and grim, the infected have gone somewhere else. Not demons, not fantasy.
Something that used to be a person and is now mostly not.

**A silhouette that only reads because of surface detail is the wrong
silhouette.** Most of the horde is seen at fifteen to twenty-five metres against
black fog, where the outline is all that survives. That is the test any of these
has to pass before the triangles are worth spending.
